# TUTI Games — лендинг

Односторінковий сайт-візитівка студії дитячих ігор. Українська мова, статична збірка.

## Стек

| Що                                    | Навіщо                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------- |
| [Astro](https://astro.build) 7        | Статична генерація, 0 KB JS за замовчуванням, `astro:assets` для картинок |
| [Tailwind](https://tailwindcss.com) 4 | Стилі; усі токени — в одному `@theme` у `src/styles/global.css`           |
| `@fontsource*`                        | Шрифти локально, з кириличною підмножиною                                 |
| Prettier + `astro check`              | Формат і перевірка типів                                                  |

Анімації — на CSS і `IntersectionObserver`, без бібліотек. Свого JS ≈1.4 KB.

## Команди

```bash
npm install        # залежності
npm run dev        # http://localhost:4321
npm run build      # статика в dist/
npm run preview    # подивитися зібране
npm run format     # Prettier
npm run check      # astro check
```

## Редагування

**Текст** — тільки `src/content/site.ts`. Розмітку чіпати не треба.

**Кольори, шрифти, рух** — блок `@theme` у `src/styles/global.css`.

**Обкладинки** — у `site.ts` вказується ім'я файлу без розширення
(`cover: "borsch-01"`). Будь-який файл із `src/assets/**` доступний за іменем;
помилка в імені зупиняє збірку зі списком доступних.

**Ілюстрації** — просто кинути файли в `_source/illustrations` і запустити
скрипт нижче: він сам перетисне їх у WebP і зробить доступними за іменем
файлу. Дописувати нічого не треба.

**Кадри з ігор** — покласти в `_source/screenshots`, дописати їх
у `scripts/prepare-assets.py` і запустити:

```bash
pip install pillow numpy
python scripts/prepare-assets.py
```

Скрипт обрізає інтерфейс Procreate, ріже широкі кадри й вирізає персонажів
із рівного тла в прозорий WebP. Далі Astro сам робить адаптивні розміри
й `srcset`.

## Дві речі, на які варто зважати

**Шрифт.** Nunito, один змінний файл на всі накреслення, повна кирилиця
разом з українською «ґ». Заголовки — 800, текст — 400/600. Браузер бере
лише latin і cyrillic (≈59 KB на два файли).

Якщо мінятимете шрифт — перевіряйте дві речі. По-перше, чи є в ньому
кирилиця: Outfit, Fredoka, Baloo та більшість «дитячих» шрифтів мають
тільки латиницю, і українська мовчки поїде на системний. По-друге,
чи виставлені в CSS `unicode-range`: у японських і CJK-шрифтів
(наприклад M PLUS Rounded 1c) fontsource їх не ставить, і браузер
тягне всі підмножини — це були 259 правил `@font-face` і 310 KB CSS.

Зараз на першому завантаженні: CSS 7 KB, шрифти 59 KB (2 файли),
свій JS ≈1.4 KB, картинки першого екрана ≈130 KB.

**Запасні картинки.** `src/assets` містить більше кадрів, ніж показує сайт —
щоб обкладинку можна було замінити одним рядком у `site.ts`. Через
`import.meta.glob` усі вони потрапляють у `dist/` (≈1.2 MB з 4.1 MB). На
швидкість сторінки це не впливає — браузер їх не запитує, — але якщо треба
вичистити деплой, приберіть невикористані файли з `src/assets`.

## Порти

Той самий сайт є ще у двох варіантах — див. [ports/README.md](ports/README.md):

- `ports/vanilla` — чисті HTML + CSS + JS, без збірки. Збігається з
  оригіналом піксель у піксель. Перегенерувати:
  `npm run build && python scripts/export-vanilla.py`
- `ports/next` — Next.js на App Router. Верстка збігається точно,
  відрізняється лише стиснення картинок.

## Що ще треба від клієнта

Позначено як `TODO` у `src/content/site.ts` і `astro.config.mjs`:

- домен (потрібен для canonical, OG і sitemap);
- пошта й соцмережі;
- фінальні назви застосунків і як 10 міні-ігор по них розподілені;
- справжні новини для блоку «Що в роботі» замість опису робіт;
- вакансії (зараз показується блок «надішліть портфоліо»);
- OG-зображення 1200×630 у `public/og.jpg` і фавікон;
- сторінки політики приватності й умов використання.

П'ять міні-ігор ще без своєї графіки — для них у сітці стоять кадри
із сусідніх ігор, позначені `placeholderArt: true`.
